PCB 设计中功率回路与信号回路的分区原则

PCB 电力电子 EMC
PCB 与硬件
发布日期:   2026-06-18

1. 分区的必要性

电力电子 PCB 同时存在大电流、高 dv/dt 的功率回路与小信号、低噪声的控制回路。若布局不当，功率回路的噪声会耦合到控制回路，导致驱动误触发、采样漂移甚至系统不稳定。

2. 分区原则

2.1 物理分区

将 PCB 划分为：

  1. 功率区：开关管、二极管、电感、变压器、大电容、采样电阻。
  2. 驱动区：栅极驱动 IC、驱动电阻、隔离器件。
  3. 控制区：MCU / DSP、运放、ADC、光耦。
  4. 辅助电源区：反激 / 正激电源、LDO。

各区之间保持一定间距，功率区与控制区之间可用接地铜皮或开槽隔离。

2.2 接地策略

  • 功率地（PGND）：承载大电流，使用大面积铺铜。
  • 信号地（AGND）：小信号回路参考地。
  • 单点连接：PGND 与 AGND 在 ADC 采样参考点或主滤波电容处单点连接，避免地环路。

2.3 采样回路

  • 电流采样（如分流电阻）的信号线采用开尔文连接，从采样电阻两端直接引出，避免功率电流在走线上产生压降。
  • 电压采样分压电阻靠近 ADC 输入端放置，缩短高阻抗走线长度。

3. 栅极驱动布线

  • 驱动回路面积尽量小（驱动电阻 → 栅极 → 源极 → 驱动地）。
  • 栅极与源极走线成对紧耦合，降低回路电感。
  • 驱动地与功率地在开关管源极就近连接。

4. 去耦电容

  • 每个 IC 的电源引脚旁放置 0.1 μF 陶瓷电容。
  • 功率级输入端放置大容量电解电容 + 高频陶瓷电容，减小母线纹波。
  • 电容尽量靠近开关管的漏-源回路。

5. 检查清单

  • 功率回路面积最小化
  • 采样线远离功率走线
  • PGND / AGND 单点接地
  • 驱动回路紧凑
  • 去耦电容位置合理
  • 大电流走线宽度 / 过孔数量满足载流要求
