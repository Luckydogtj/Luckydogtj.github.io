## 1. 为什么需要构网型变流器

随着新能源渗透率不断提高，传统同步机占比下降，电力系统的惯量与阻尼减弱。**跟随型变流器（Grid-Following, GFL）**依赖电网电压进行锁相，在弱电网下容易出现稳定性问题。

**构网型变流器（Grid-Forming, GFM）**通过主动建立电压与频率，具备类似同步机的外特性，能够为系统提供惯量与阻尼支撑。

## 2. GFM 与 GFL 的核心区别

| 特性 | GFL（跟随型） | GFM（构网型） |
|------|---------------|---------------|
| 电压源 | 依赖电网 | 自主建立 |
| 锁相环 | 必需 | 可弱化或去除 |
| 惯量支撑 | 无 | 可提供虚拟惯量 |
| 弱电网适应性 | 较差 | 较强 |

## 3. 典型 GFM 控制策略

### 3.1 下垂控制（Droop Control）

通过有功-频率（P-f）与无功-电压（Q-V）下垂特性，使变流器共享负荷并参与频率调节：

```
ω = ω* - m_p (P - P*)
V = V* - n_q (Q - Q*)
```

### 3.2 虚拟同步机（VSG）

在控制环路中引入虚拟转子运动方程：

```
J dω/dt = (Pm - Pe)/ω - D(ω - ωg)
```

其中 `J` 为虚拟惯量，`D` 为阻尼系数，使变流器具备与同步机相似的频率响应特性。

## 4. 关键挑战

- **功率耦合**：在低压电网中阻性线路导致有功无功耦合，需做解耦控制。
- **环流抑制**：多台 GFM 并联时需抑制环流。
- **故障穿越**：构网型变流器需具备限流与故障穿越能力。
