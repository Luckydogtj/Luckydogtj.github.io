## 1. 为什么需要小信号建模

电力电子变换器是强非线性的时变系统。为进行控制器设计，需在稳态工作点附近进行线性化，得到小信号模型。

## 2. 状态空间平均法

Buck 变换器在连续导通模式（CCM）下：

- **导通阶段（0 ~ dTs）**：电感电流上升，`L di/dt = Vg - Vo`，输入经电感向负载与电容供能。
- **关断阶段（dTs ~ Ts）**：电感电流下降，`L di/dt = -Vo`。

对状态变量 `iL`、`vC` 取平均并加入小信号扰动，经整理可得控制到输出的传递函数 `Gvd(s)`。在忽略电感等效电阻与电容 ESR 的理想条件下，Buck CCM 的标准形式为：

```
Gvd(s) = Vg / (1 + s/(Q*ω0) + (s/ω0)^2)
```

其中 `ω0 = 1/√(LC)`，`Q = R√(C/L)`，直流增益为 `Vg`。

考虑电容 ESR 时，传递函数增加一个零点：

```
Gvd(s) = Vg * (1 + s*ESR*C) / (1 + s/(Q*ω0) + (s/ω0)^2)
```

## 3. 环路补偿

### 3.1 性能指标

- 相位裕度 ≥ 45°
- 增益裕度 ≥ 10 dB
- 带宽约为开关频率的 1/10 ~ 1/5

### 3.2 Type-II 补偿器

适用于电流模式控制（单极点特性）：

```
Gc(s) = K * (1 + s/ωz1) / (s * (1 + s/ωp1))
```

### 3.3 Type-III 补偿器

适用于电压模式控制（双极点特性），提供两个零点补偿 LC 谐振峰：

```
Gc(s) = K * (1 + s/ωz1)(1 + s/ωz2) / (s * (1 + s/ωp1)(1 + s/ωp2))
```

## 4. MATLAB 验证

可使用 `sisotool` 或 `bode` 命令绘制开环传递函数伯德图，调整补偿器零极点位置以满足裕度要求。

## 5. 注意事项

- 实际电路中 ESR 会引入一个零点，不可忽略。
- 数字控制带来的延时（一拍滞后）会降低相位裕度，建模时需乘以 `e^(-sTd)`。
