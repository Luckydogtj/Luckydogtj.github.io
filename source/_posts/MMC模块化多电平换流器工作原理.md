## 1. MMC 拓扑

模块化多电平换流器（Modular Multilevel Converter, MMC）由六个桥臂组成，每个桥臂由 N 个半桥子模块（Submodule, SM）与一个桥臂电感串联而成。

```
      上桥臂 (N 个 SM + L_arm)
        │
 相输出 ─┤
        │
      下桥臂 (N 个 SM + L_arm)
```

通过投入不同数量的子模块，可在交流侧逼近正弦波。电平数为 `2N+1`。

## 2. 子模块工作状态

半桥子模块由两个 IGBT（T1、T2）、两个反并联二极管与一个电容 C 组成：

- **投入状态**：T1 导通，T2 关断，电容接入回路，输出电压为 +Uc（半桥子模块仅能输出 0 或 +Uc，无法输出负电压）。
- **切除状态**：T1 关断，T2 导通，电容旁路，输出电压为 0。
- **闭锁状态**：T1、T2 均关断，通过二极管旁路。

## 3. 调制策略

常用**最近电平逼近调制（NLM）**：根据参考电压选择投入最接近电平数的子模块。在高电平数（N 较大）场合，NLM 无需高频载波即可获得较低的谐波含量。

## 4. 电容电压均压

子模块电容电压需要保持均衡。常用方法：

1. **排序法**：每个控制周期对所有子模块电容电压排序，根据桥臂电流方向优先投入电压最低（或最高）的子模块。
2. **均衡控制**：引入均压系数，通过 PI 调节使各子模块电压收敛到平均值。

## 5. 环流抑制

MMC 三相之间存在内部环流（主要为二倍频负序分量），会增加器件损耗。通常通过在 dq 坐标系下提取二倍频负序电流并加以闭环抑制。

## 6. 应用场景

- 柔性直流输电（VSC-HVDC）
- 新能源并网（大规模光伏 / 风电）
- 中高压电机驱动
- 静止同步补偿器（STATCOM）
